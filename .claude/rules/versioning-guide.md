# Versioning guide

Version numbering: MAJOR.MINOR.PATCH, starting from 0.86.0. Releases
are named by the version alone. Pre-releases carry a suffix:
0.86.0-pre1, 0.86.0-pre2, then 0.86.0.

Current: 0.86.0-pre2.

# Full product name

Examples: dosbox-automation 0.86.0-pre1, dosbox-automation 0.86.0.
